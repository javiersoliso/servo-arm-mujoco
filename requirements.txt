# Pinned because the *combination* matters. Install into a clean virtualenv:
#
#   python3 -m venv venv
#   venv/bin/pip install --index-url https://download.pytorch.org/whl/cpu torch==2.13.0
#   venv/bin/pip install -r requirements.txt
#
# The clean venv is not a style preference. Installing the CUDA build of torch
# leaves nvidia-*/cuda-* packages behind; a later CPU-only torch still loads
# ~49 cuda.bindings modules from them, and in the same process as MuJoCo that
# corrupts the heap. The symptom is a SIGSEGV inside libc free() while
# stable-baselines3 builds its optimiser -- a traceback that points squarely
# at torch and is completely misleading. It is also NONDETERMINISTIC, so a
# single passing run proves nothing; the fix was confirmed over 10 consecutive
# trials. Full write-up: docs/physics_debugging.md, "the training segfault".
